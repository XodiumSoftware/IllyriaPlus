# Server Rules

The server rules are enforced in-game via the Rules command.

1. **Be respectful** — No harassment, hate speech, or toxicity
2. **No griefing** — Protected by anti-griefing systems, but respect builds
3. **No cheating** — No hacked clients, x-ray, or exploits
4. **No spam** — Keep chat readable
5. **Use common sense** — If it feels wrong, don't do it

> Check `/rules` in-game for the authoritative, up-to-date list.
