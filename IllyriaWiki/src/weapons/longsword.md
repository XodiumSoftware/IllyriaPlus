# Longsword

A swift, elegant blade that trades raw damage for speed.

## Stats

| Attribute     | Value           |
| ------------- | --------------- |
| Base Item     | Netherite Sword |
| Attack Damage | 8.0             |
| Attack Speed  | 1.6             |

## Crafting

Upgrade a **Netherite Sword** in a smithing table:

| Slot     | Ingredient                          |
| -------- | ----------------------------------- |
| Template | Netherite Upgrade Smithing Template |
| Base     | Netherite Sword                     |
| Addition | Echo Shard                          |

## Playstyle

The Longsword is the fastest custom weapon. With 1.6 attack speed, you can land
more hits per second — ideal for aggressive playstyles and quickly applying
on-hit effects like Fire Aspect.
