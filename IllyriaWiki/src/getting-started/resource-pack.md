# Resource Pack

IllyriaRPG uses a custom resource pack to enhance your experience with custom weapon models, textures,
and UI elements.

## Automatic Installation

The resource pack is **automatically served** when you join the server. Simply accept the prompt and it will be
applied on every join.

## Manual Installation

If you disabled server resource packs, download it manually from the
[releases page](https://github.com/XodiumSoftware/IllyriaPlus/releases) and place it in your `resourcepacks`
folder.

## What's Included

- Custom 3D weapon models (Greatsword, Halberd, Longsword)
- Custom painting variants
- Boss bar icons
- UI and text overrides
