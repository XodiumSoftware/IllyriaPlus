# Xaero's Maps

The server officially supports **Xaero's World Map** and **Xaero's Minimap**.

## Features

- **Persistent World ID** — Waypoints and map data are tied to the server's world, so they stay consistent
  across sessions and client restarts
- **World Sync** — Map data syncs automatically when you switch dimensions/worlds

## Setup

1. Install Xaero's Minimap and/or World Map on your client
2. Join the server — the mod is automatically detected
3. Your waypoints and explored map areas are synced with the server
