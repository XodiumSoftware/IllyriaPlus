# Fabric & JEI

If you're playing on a **Fabric or NeoForge client with JEI installed**, the server automatically syncs custom
recipes to your recipe book.

## Features

- See custom weapon recipes (Greatsword, Halberd, Longsword) directly in JEI
- Browse all custom vanilla-style recipes (chainmail, wool-to-string, etc.)

## Setup

1. Install **Fabric Loader** (or NeoForge)
2. Install **JEI** ([Just Enough Items](https://modrinth.com/mod/jei))
3. Join the server — Fabric/NeoForge clients are detected automatically on join

## Notes

- Vanilla clients are completely unaffected
- Synced recipes only appear for Fabric/NeoForge + JEI players
- Recipe sync happens automatically on every join
