# AppleSkin

The server officially supports **AppleSkin**, syncing your exact food stats to the client.

## Features

- **Saturation overlay** — Your real saturation value is synced every tick, so the mod's saturation/shader
  overlay on the hunger bar is accurate
- **Exhaustion preview** — See exactly how much saturation a food will restore before eating it
- **Natural regeneration state** — The mod knows whether natural health regeneration is enabled per-world,
  keeping its hunger/regen indicators correct everywhere

## Setup

1. Install [AppleSkin](https://www.curseforge.com/minecraft/mc-mods/appleskin) on your client
2. Join the server — the mod is automatically detected
3. The hunger bar overlay and food tooltips now show live server values

## Notes

- Vanilla clients are completely unaffected
- Syncing only starts for players who have AppleSkin installed
