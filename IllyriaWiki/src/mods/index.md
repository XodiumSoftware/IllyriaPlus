# Client Mod Support

IllyriaRPG works with all vanilla clients, but enhances the experience for players using certain mods.

## Supported Mods

| Mod                                          | Benefit                                        |
| -------------------------------------------- | ---------------------------------------------- |
| [Xaero's World Map / Minimap](xaeros.md)     | Server-tracked waypoints & shared map data     |
| [Fabric + JEI](fabric-jei.md)                | Full recipe book sync for custom recipes       |
| [AppleSkin](appleskin.md)                    | Accurate saturation & hunger overlay           |

## Requirements

Playing with **no mods at all** is completely fine — these are optional enhancements.
