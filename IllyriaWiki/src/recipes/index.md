# Recipes

IllyriaRPG adds convenient vanilla-style recipes for common QoL needs.

> Recipe images are generated with the [Crafting Recipe Generator](https://crafting.thedestruc7i0n.ca/).
> See [assets/recipes/README.md](../assets/recipes/README.md) for the contribution workflow.

## Smelting & Blasting

| Recipe                  | Method        | Image                                                                                |
| ----------------------- | ------------- | ------------------------------------------------------------------------------------ |
| Rotten Flesh to Leather | Furnace       | ![Rotten Flesh Smelting recipe](../assets/recipes/rotten_flesh_smelting.png)          |
| Diamond Recycling       | Blast Furnace | ![Diamond Recycling recipe](../assets/recipes/diamond_recycling_blast_furnace.png)   |

**Diamond Recycling** accepts any diamond tool, weapon, or armor piece (including horse armor).

**Rotten Flesh** can be smelted in a furnace, smoker, or campfire — same recipe in each.

## Stonecutting

| Recipe           | Method      | Image                                                                          |
| ---------------- | ----------- | ------------------------------------------------------------------------------ |
| Custom Paintings | Stonecutter | ![Custom Paintings recipe](../assets/recipes/custom_paintings_stonecutter.png) |

Custom paintings are cut in the stonecutter using **1 Painting + 1 material**. Open a stonecutter
in-game to browse all available custom painting variants.
