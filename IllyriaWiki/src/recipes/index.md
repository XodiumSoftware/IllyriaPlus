# Recipes

IllyriaRPG adds convenient vanilla-style recipes for common QoL needs.

## All Recipes

| Recipe                  | Method         | Input                    | Output              |
| ----------------------- | -------------- | ------------------------ | ------------------- |
| Chainmail Helmet        | Crafting Table | 5 Iron Bars              | Chainmail Helmet    |
| Chainmail Chestplate    | Crafting Table | 8 Iron Bars              | Chainmail Chestplate |
| Chainmail Leggings      | Crafting Table | 7 Iron Bars              | Chainmail Leggings  |
| Chainmail Boots         | Crafting Table | 4 Iron Bars              | Chainmail Boots     |
| Wool to String          | Crafting Table | 1 Wool (any color)       | 4 String            |
| Ice Breakdown           | Crafting Table | 1 Blue Ice               | 9 Packed Ice        |
| Packed Ice Breakdown    | Crafting Table | 1 Packed Ice             | 9 Ice               |
| Nether Wart Breakdown   | Crafting Table | 1 Nether Wart Block      | 9 Nether Wart       |
| Rotten Flesh to Leather | Furnace        | Rotten Flesh             | Leather             |
| Wood to Log             | Crafting Table | 1 Wood Block (any type)  | 4 Matching Logs     |
| Diamond Recycling       | Blast Furnace  | 1 Diamond Tool/Armor     | 1 Diamond           |
| Custom Paintings        | Stonecutter    | 1 Painting + material    | 1 Custom Painting   |

## Notes

- **Chainmail Armor** uses vanilla armor crafting patterns with Iron Bars
- **Diamond Recycling** accepts any diamond tool, weapon, or armor piece (including horse armor)
- **Rotten Flesh** can be smelted in a furnace, smoker, or campfire
- **Wood to Log** converts wood blocks (e.g. Oak Wood) back to 4 logs of the same type
- **Custom Paintings** are cut via the stonecutter
