# More Recipes

Additional handy recipes available on the server:

| Recipe              | Description                                  |
| ------------------- | -------------------------------------------- |
| **Ice Breakdown**   | Break packed/blue ice back into regular ice  |
| **Nether Wart Block** | Convert nether wart blocks back to nether wart |
| **Rotten Flesh**    | Process rotten flesh into usable material    |
| **Wood Log**        | Convert between log types                    |
| **Painting**        | Custom painting recipes                      |
