## Effect

Enchanting a harness with Nimbus increases the flying speed of the **Happy Ghast**
wearing it. The bonus applies as soon as the harness is equipped and is removed
when the harness is taken off.

## Speed Multiplier per Level

| Level | Speed Multiplier |
| ----- | ---------------- |
| 1     | 1.5×             |
| 2     | 2.0×             |
| 3     | 2.5×             |
| 4     | 3.0×             |
| 5     | 3.5×             |

## Notes

- Only works on **Happy Ghasts** wearing the enchanted harness (harness slot)
- Anvil cost: 2 levels
- Speed returns to normal when the harness is removed
