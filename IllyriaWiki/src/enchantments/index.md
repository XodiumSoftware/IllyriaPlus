# Enchantments

IllyriaRPG adds four custom enchantments obtainable through the enchanting table,
anvils, and villager trading — just like vanilla enchantments.

## Custom Enchantments

| Enchantment              | Applies To   | Effect         |
| ------------------------ | ------------ | -------------- |
| [Embertread](embertread.md) | Boots      | Walk on lava   |
| [Nimbus](nimbus.md)      | Boots        | Movement abilities |
| [Tether](tether.md)      | Tether items | Tether entities    |
| [Vinemine](vinemine.md)  | Tools        | Vein mining    |

## [Vanilla Tweaks](vanilla-tweaks.md)

Adjusted behavior for Feather Falling, Fortune, and Silk Touch.
